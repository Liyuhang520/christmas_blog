# 坑蒙拐骗奇遇记 - 圣诞版博客 🎄

这是一个充满圣诞气氛的个人博客网站，讲述了一个有趣的圣诞故事。

## ✨ 特性

- 🎅 圣诞主题设计，带有雪花动画效果
- 🎬 支持上传和播放视频
- 🖱️ 鼠标跟随特效
- 📱 响应式设计，支持移动端访问
- 🎨 精美的中国书法风格标题

## 🚀 在线访问

访问 GitHub Pages 链接即可查看完整网站。

## 📖 故事内容

讲述了从玖福记买鸡架开始，到中街祈福的一系列有趣经历，最后送上圣诞祝福。

## 🛠️ 技术栈

- HTML5
- CSS3 (原生样式，包含动画和渐变效果)
- JavaScript (原生 JS)
- Canvas (雪花动画)

个人项目，仅供学习和分享使用。
